## A1｜大戶真實集中驗證（研究型候選名單）

A1 母池**只取該週集保 >400 張大戶週增 TOP50**，逐一檢查：
- 400張以上持股占比增幅 **≥1.00pp**；千張以上持股占比同步 **>0pp**
- 小額持股（TDCC 分級第 1～5 級、約 20 張以下）合計占比 **<0pp**
- 官方 **外資（不含外資自營商）＋投信**同一比較週期合計**淨買超 >0 張**；必須具備完整可驗證的日期覆蓋，避免誤拿單日充當整週
- TDCC **集保庫存總股數**前後週變動幅度 **≤0.5%**，只用來作為疑似增減資／分母異動警示；這並非公司正式發行股本，也**不能保證排除過戶、ETF調整或公司與關係人交易**

畫面將股票分成「**候選待公告**」、「資料待補」、「條件未通過」三類，未通過不代表公司作帳，候選也**不能認證一定是主力吸籌**。對每筆候選仍須核對公司重大訊息、股本異動、董監持股及交易揭露。股東人數下降為輔助佐證，非硬門檻。

初次增加 TDCC level 17 庫存總股數時，過去保存的快照若沒有該欄，無法重建歷史庫存股數，因此首期部分股票將顯示「資料待補」，待下一次新 TDCC 週數據累積後才會恢復驗證，**不得回填假數據**。僅上市／上櫃普通股，來源 TDCC + TWSE/TPEX 官方日報；若法人日報格式改動或某日遺失，不會計入 A1 候選。網站規則程式在 `rules/a1-screening.js`，官方法人歷史抓取在 `scripts/a1_institutional.py`。

## 真實資料與歷史累積

- A1 法人資料依證交所官方開休市表回補每個顯示週期，不再依賴本機是否存有當日行情。年度表未收錄的臨時休市，另以經查證的交易所公告補充（日期、原因、公告連結保存在 `trading_calendar.json`）；目前包含 2026-10-23 颱風休市。未經公告確認的缺日仍保留為缺漏，不從空報表推測休市。新增臨時休市須核對交易所公告後更新 `VERIFIED_EXTRA_CLOSURES`。
- 名冊保留官方上市／上櫃日期，產生歷史快照與 TOP50 前排除當週尚未掛牌的股票，避免後來掛牌公司倒灌舊週排名。歷史範圍仍受目前名冊限制，尚未完整重建已下市或轉板公司的歷史名冊。
- 每份法人報表核對回傳日期與買賣超加總，保存完整市場報表及來源／SHA-256／解析版本，避免名冊新增股票後仍沿用被舊名冊裁切的快取。缺少個股列不補零。
- 「資料待補」分類只包含未發現硬條件失敗的股票；已有條件失敗者仍可同時缺資料。A1 頁另列上市、上櫃覆蓋與全部含缺值股票，以免把分類數字誤認成資料完整度。
- `python scripts/verify_snapshot.py` 會核對兩市場覆蓋及所有個股的 A1 交易日期、缺漏原因、週買賣超與原始每日快取是否一致。

- 官方大戶是 **TDCC 400,001 股以上分級合計（12–15級）**；變化單位是 **百分點 pp**。
- 系統在 `data/auto_snapshots.json` 成功產生、並完成網站發布之前，只顯示**2026-10-16 圖片案例**，**不是當日行情**。
- 首次官方擷取只有 1 個集保週別，**兩週**才有大戶變化和排行榜，**三週**才有完整四類分類。
- 已加入 **D1／D1+／C2+／C1 篩選**，來源是原 D1 Radar v2026.09.1 的規則，程式位於 `rules/d1-screening.js`，**完全不依賴 Lovable 執行或付費額度**。
- 僅納入官方來源可核對的融資週差；上櫃歷史融資 API 若缺失，該股 D1/C2+ 無法判定，絕不以最新餘額冒充歷史值。
- D1 = 大戶週增至少 1pp、週報酬不超過 0%、融資餘額週減少；D1+ 除 D1 外，還要求大戶至少 2pp 與融資週減幅至少 5%。
- C2+ = 大戶至少 1pp、週報酬不超過 3%、融資不增加；C1 = 大戶至少 0.5pp、週報酬不超過 5%。每檔股票只標記**最高分級**（D1+ > D1 > C2+ > C1）。
- 少於必要價格／大戶／融資資料時不會猜測、補零，無法判定時可視為未有足夠資料，不等同於不符合策略。
- 預設篩選與原 D1 Radar 的後端資料庫互相獨立，**不會把原系統的歷史勝率自動搬過來**；只使用本網站已存的 TDCC/TWSE/TPEx 週快照。
- 官方服務停擺可能導致更新失敗；請檢查 Actions 日誌。網址穩定不代表官方資料已更新。
- 收藏和 CSV 匯入存在瀏覽器本機；不會同步到 GitHub。

## 產業資金流向

- 「總覽」入口與側欄「產業資金流向」提供產業面積分布、淨買超／淨賣超排行、個股明細及 CSV 匯出，可切換週別、上市／上櫃、外資／投信／自營商／三大法人合計。
- 估算口徑：每檔完整週期法人淨買賣張數 × 1,000 × 該週期末官方收盤價，再按官方產業分類加總。單位為新台幣元，介面以億元呈現。這是法人偏好的代理指標，不是實際成交金額或全市場資金流，不包含散戶，也不是即時資料。
- 區塊面積為該產業淨額占同方向（淨流入或淨流出）產業合計的比例；先在產業內抵銷買賣，再計方向占比。
- 使用快照全體股票，不限 TOP50。分類取 TWSE 公司名冊的「產業別」或 TPEx 的 SecuritiesIndustryCode。採最近取得的分類，不能還原歷史改類、下市或轉板。未知代碼（含不代表產業的存託憑證分類）保留原碼、顯示未分類，不塞進其他業。
- 只有完整法人期間及同週期末收盤價的股票才納入估算；缺漏不補零，也不使用較新的股價替代。畫面揭露總體及各產業可估算檔數；資料不完整會改變排名。自行匯入和內建圖片不參與此統計。
- 排程更新時自動重建分類與期末價格，前端隨現有快照同步機制讀取。測試：`python -m unittest discover -s tests -v`、`node --test tests/industry-flow.test.cjs`。

## VCP 縮量待突破｜每日技術雷達（非 XQ）

- 首頁側欄進入「VCP 縮量待突破」，網址 `vcp-radar.html`。無須 XQ 或任何券商帳戶。
- 以 TWSE/TPEX 官方日 OHLCV（交易日開高低收、成交股數）辨識 **75 個交易日固定三段近似 VCP**，以最近一段前 25 日高點為樞紐；收盤仍低於樞紐 1%～3%、末段 25 日振幅≤12%、量縮 10 日／50 日 <0.9、至少 500 張且收盤在 50 日線之上才納入「縮量近樞紐」觀察。符合首段≥10%且三段依序縮小、末段≤10%、量縮比<0.7 才進一步歸為「嚴格三段收縮」。
- 完整 MA200 趨勢樣板及 52 週高低點需 220／250 根歷史日 K 才能判定；不足時明確標示「初步觀察」，並不宣稱已符合 Minervini 完整 VCP。
- 原本 A1、D1 週資料維持獨立。新頁會用最新官方週快照交叉顯示大戶／散戶與法人，提供市場、距突破區間、籌碼條件、股票搜尋與 CSV 匯出。
- 官方指定日期歷史行情會逐次回補（每次兩市場各最多 65 個缺失的平日（可由環境變數調整））；新部署初期的 0 檔可能只是 K 線不足。`data/vcp_daily.json` 僅保存在倉庫，Pages 只部署輕量級結果 `data/vcp_signals.json`。
- `scripts/vcp_daily.py` 實作與 `tests/test_vcp.py` 自動化測試。上市現價來源 TWSE STOCK_DAY_ALL、上櫃 TPEx daily_close_quotes，歷史行情使用 TWSE MI_INDEX 與 TPEx afterTrading/otc 並按來源欄名驗證。最新日資料可能延遲、歷史回補可能被官方限制；不補假資料。
- 股價未還原除權息；固定三段並非真正波段 VCP；僅供預警觀察而非買進／回測績效。


## D1／D1+ 自動帶入 VCP 技術雷達

- 在「D1 / D1+ / C2+ / C1」頁面按 **D1／D1+ 自動帶入 VCP** 或 **僅 D1+ × VCP**，開啟 `vcp-radar.html?mode=d1`／`?mode=d1plus`。
- 交叉名單以**最新正式官方** `auto_snapshots.json` 快照逐檔套用現有 `rules/d1-screening.js` 的 `qualify()`；與 D1 頁面使用**同一份規則**，不複製或放寬 D1 條件。不使用內建圖片快照或使用者匯入的舊 CSV 冒充當週訊號。
- `data/vcp_signals.json` 新增 `assessments` 字典，依每檔股票代號提供日 K 筆數、行情日期、樞紐價、距離百分比、三段振幅、10／50 日量縮比、完整技術狀態及未達條件原因；**未通過 VCP 的 D1 股票一樣保留顯示**。
- 每種 D1 技術狀態會分別標示「嚴格三段收縮」「縮量近樞紐」「未符合」「資料不足」及「行情落後」。資料不足不會捏造樞紐價、技術訊號或成交量。
- D1 模式預設**不套用距離／VCP合格過濾**；使用者可自行縮小狀態與距離。獨立 VCP 縮量候選模式維持原本的過濾方式。
- 頁面會並列標示 D1 官方週籌碼日期與上市／上櫃 VCP 盤後行情日期；不是即時通知，也不是已回測的可交易訊號。
- 測試：`python -m unittest discover -s tests -p 'test_vcp.py' -v` 及 `node --test tests/vcp-integration.test.cjs`。



## D1 動能啟動雷達（研究預覽）

- 網站新增 [D1 動能啟動雷達](momentum-radar.html)；自動套用**最新正式官方** D1／D1+ 週選股結果，不改動原版 D1 分級，也不移除 VCP 與前五期歷史清單。
- 在已保存的官方日 K 資料上運算：加權收盤價 `(H+L+2C)/4` 的 MACD(12,26,9) 柱狀體剛翻正；Bollinger(20,2) 帶寬上升且上軌上升、下軌下降；股價在上揚 MA20 之上；當日量至少 500 張。可切換 MACD 三日翻正、布林帶寬、MA20 上揚比較 1/3/5 日、成交量、距離 MA20、VCP 現況。
- 盤後資料每次由 GitHub Actions 從 `data/vcp_daily.json` 重新產生 `data/momentum_signals.json` 供網頁讀取，不部署原始全市場日 K。缺少 80 日 K、最近80個市場交易日出現個股資料缺漏，或最新交易日資料落後時，**標記待補，不會猜測訊號**。
- 「連三個交易日收盤在當日 MA20 以下」標記為**出場警示**，不是可交易成交回報；尚無歷史進出場績效。EMA 起始值可能與 XQ 略有差異；股價未還原除權息或股本變動。
- 目前沒有經過生存者偏差控制、除權息調整、手續費／滑價、跨多空期間的公平 A/B/C/D 回測。**頁面僅供觀察，不顯示無法驗證的勝率、報酬或複利結果。**
- 測試：`python -m unittest discover -s tests -p 'test_momentum.py' -v`，部署前將產出最新盤後訊號。
